# Snips&Pics documentation

Snips&Pics is a handheld photobooth. The camera sits on the front of the box, a 3.5" touchscreen sits on the side in portrait (320×480), and the shutter button sits on top. The same Python app runs on Windows with a webcam while the box is still being built.
